# Quick Setup Guide

## 🚀 Get Your Portfolio Live in 5 Minutes

### Step 1: Setup Formspree (2 minutes)

1. Go to https://formspree.io
2. Click "Sign Up" (free account)
3. Click "New Form"
4. Copy your Form ID (e.g., `xvgkqyzw`)
5. Open `index.html`
6. Find line 362: `<form action="https://formspree.io/f/YOUR_FORM_ID"`
7. Replace `YOUR_FORM_ID` with your Formspree ID

### Step 2: Update Your Info (2 minutes)

1. Open `index.html`
2. Update these sections:
   - **Line 18-28**: Update URLs in meta tags (replace `annantsaharan.github.io` with your URL)
   - **Contact Section**: Update email, phone, location
   - **Social Links**: Update LinkedIn URL
   - **Projects**: Add your project links

### Step 3: Deploy (1 minute)

#### Option A: GitHub Pages (Recommended)
1. Create GitHub account (if you don't have one)
2. Create new repository
3. Upload all files
4. Go to Settings > Pages
5. Select branch: `main`
6. Done! Your site is live

#### Option B: Netlify (Easiest)
1. Go to https://netlify.com
2. Sign up (free)
3. Drag & drop your folder
4. Done! Instant deployment

#### Option C: Vercel
1. Go to https://vercel.com
2. Sign up with GitHub
3. Import your repository
4. Deploy!
